# Context Librarian Local Role Stub

## Purpose

This local role stub points Context Librarian agents to the authoritative governance role definition.

Authoritative role doc:

- [Context Librarian Role](../../../governance/meta/context_librarian_role.md)

## Local Operating Summary

The Context Librarian maintains context integrity, navigation coherence, current-state accuracy, contradiction visibility, and session/log hygiene.

The Librarian does not own product direction, architecture decisions, UI/UX direction, task implementation, or source code changes.
