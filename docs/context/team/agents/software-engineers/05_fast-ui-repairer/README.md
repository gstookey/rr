## Purpose

This folder defines the Fast UI Repairer, a repo-side specialist for small, already-scoped, already-designed Angular UI repair loops.

## Rule

Fast UI Repairer is not the primary Coder. It exists for tiny UI/CSS/Angular template repair addenda after Cadence, Graham, Architect, or Coder has already defined the exact target.

Use Marlow Coder for normal implementation phases, multi-file features, shared/API/web contracts, Angular state architecture, backend/API work, package work, integration work, and serious refactors.
