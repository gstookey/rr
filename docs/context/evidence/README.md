# Evidence

## Purpose
This folder preserves source material and reference artifacts that inform the context system.

Evidence is informative, not governing, until it is synthesized into canonical or governance documents.

## Subfolders
- `raw/` - source register and raw-source summaries
- `images/` - screenshots and visual reference artifacts

## Rule
Do not treat evidence files as current truth unless that truth has also been rolled up elsewhere.
