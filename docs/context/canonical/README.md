# Canonical

**Created:** 2026-08-25

`canonical/` holds the compiled, interlinked project wiki: what the project currently *believes*, synthesized from evidence, decisions, and sessions. Evidence is informative; canonical pages are the answer of record. When a canonical page and `docs/CURRENT_STATE.md` disagree about what is *implemented*, CURRENT_STATE wins and the disagreement goes in the contradiction register.

## Pages

- [Current Priorities](current_priorities.md) — the compact operating picture: what matters now, sequencing, recommended next lane.
- [Project Overview](project_overview.md) — what Project Road Runner is, who it is for, and the horizon.
- [Technology Stack](technology_stack.md) — the intended stack and the rationale behind it (design direction until stood up).
- [Isolated Network Constraints](isolated_network_constraints.md) — what we know and do not know about the target environment.
- [Context System](context_system.md) — how this docs corpus is organized and why.

## Rule

A canonical page states current belief with its date and provenance. It never presents future capability as implemented, and it labels temporary constraints with their expiration horizon (AGENTS.md "What to avoid").
