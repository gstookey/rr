# User Workflow — Graham's operating loop

**Created:** 2026-08-25

1. **Open** a session from `bootstrap/START_HERE.md` (or paste the Axium bootstrap prompt from `team/agents/systems-engineer/prompt_templates.md`).
2. **Raise** ideas, constraints, feedback. Axium turns them into structure; nothing is activated without Graham's word.
3. **Dispatch** bounded work via Axium-generated prompts to the right role (Rin / Marlow / Verin / Vera / Ember / Cadence).
4. **Review** the result. PRs reach Graham click-ready or not at all (contract rule 18).
5. **Close** with the session rollup checklist so the next session starts from durable truth.

Keep sessions in one well-oriented thread; fan out only when a gate justifies it.
