ACME Workshop — S1 mockup 3 of 3: the sign-in surface

There is no username field and no password field on this page, and that absence is the design. Sign-in is a full-page navigation away to the gateway, which runs the OIDC authorization-code flow with Keycloak and returns the browser to / holding nothing but an HttpOnly session cookie. The Angular application never receives a credential, never receives a token, and carries no identity-provider SDK — so there is nothing in it for a script on the page to steal.

What is deliberately not here

No credential form, no "remember me", no password reset, no account chooser, no multi-tenant "which organisation?" picker (a group is a claim, never something the browser asserts — V8, DA-D3), no branding per tenant on the signed-out page: before a session exists, ACME does not know whose brand to wear, and guessing from a hostname or a URL parameter would be the first tenancy leak in the Building.
